# Motion brief (from reference reel, instagram.com/reel/Df-ubB6s7Nj)

Reel = promo for spatialsites.co (AI-built 3D sites). Seen via 26 sampled frames; exact easing/timing unknown.

## Observed
- FORMA pizza site: one hero object, scroll swaps its pose + background colour + headline; camera/stage fixed. Leader-line labels on one state.
- EMBER restaurant: dish hero swaps on scroll with title/price; fire/steam for life.
- Demos: clothes rail with variants, "Pick a pair off the wall" sneaker grid, glowing sneaker on dark floor, sunglasses "Look closer" zoom, cans with colour shifts.

## Brief for KRSH
1. One hero object, fixed stage; scroll swaps pose, section colour, headline.
2. Section colour shifts within the design system (graphite/ivory + the one gold accent only).
3. Hairline leader-line labels (leather / laces / sole) = first beat of "The Deconstruction".
4. "Look closer" scroll zoom into a detail (stitching, sole).
5. Hover-lift shoe grid ("pick a pair off the wall") as a Collection entry idea.
6. Subtle atmosphere (glow/reflection), no particles/gradients beyond the system.
7. Fallbacks: reduced-motion = single still pose with static labels; mobile = fewer frames / lighter float.

## Cautions
- `public/media/sneaker.glb` is one mesh: pose/colour/zoom states are feasible; pulling the shoe apart needs generated frames or a segmented model.
- Borrow mechanics, not layouts (other studio's work).
